MOC_Grid

Calculates a 2-D (planar or axisymmetric) nozzle with the method of characteristics.

See README.md in the top-level folder for the build steps and the full
MOC_Grid -> Streamline Tracing Tool workflow. In short: set Print Option to Full, click
Calculate MOC Grid, choose a folder for the results, and then click Run Streamline Tracing
Tool. MOC_Grid saves MOC_Grid.inp (its own inputs) and STT2001.inp (ready-to-run input for
STT2001) in that folder.

A MOC_Grid *.inp file can be loaded again with File > Open.
