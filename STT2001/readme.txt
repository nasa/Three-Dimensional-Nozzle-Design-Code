Streamline Tracing Tool

Normally this program is started from MOC_Grid with the "Run Streamline Tracing Tool"
button. It then opens with the STT2001.inp that MOC_Grid saved, in the folder that holds the
MOC_Grid results. See README.md in the top-level folder for the full workflow.

To start it on its own, run STT2001.exe and use File > Open to select a *.inp file (or pass
the *.inp as the command-line argument). Opening a file switches to that file's folder, because
the files named in the .inp are looked up there. A *.inp file can be saved for later re-use
with File > Save As.
